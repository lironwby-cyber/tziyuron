# ציורון

אפליקציית ווב (PWA) בעברית לשמירת הציורים של הילדים. מצלמים ציור, הדף מזוהה, מיושר והרקע מתנקה, והציור נשמר באוסף של הילד לפי גיל.

## מה יש בגרסה 1.0
- ילדים עם שם, תאריך לידה ותמונת פרופיל. הגיל מחושב ליד כל פריט.
- סריקה במצלמה עם זיהוי דף חי, צילום אחד או כמה ברצף, ייבוא מהגלריה.
- יישור פרספקטיבה, ניקוי רקע (הדף נהיה לבן, הצבעים נשמרים), חיתוך ידני. המקור נשמר לצד הגרסה הנקייה.
- סוגי פריטים: ציור, תמונה, וידאו, הקלטת קול, אבן דרך, זיכרון כתוב.
- הקלטת קול של הילד על כל ציור, עם גל קול חי. הוספת סרטון לציור.
- ציר זמן לפי גיל, גלריה, חיפוש בכל הילדים, בחירה מרובה.
- ספר דיגיטלי: כריכה, עמוד לכל ציור, סידור, הדפסה או שמירה כ-PDF.
- גיבוי ל-ZIP רגיל (תיקייה לכל ילד) ושחזור ממנו. תזכורת לגבות.
- עובד בלי רשת אחרי הביקור הראשון, מצב כהה, אפשר להתקין למסך הבית.

## פרטיות
אין שרת ואין חשבון. הכול נשמר ב-IndexedDB בדפדפן של המכשיר. לכן הגיבוי חשוב.

## הרצה מקומית
```
python3 -m http.server 8080   # ואז http://localhost:8080
```
מצלמה ומיקרופון דורשים https או localhost.

## בדיקות
```
npm test            # בדיקות יחידה (Node 20+)
npm run test:e2e    # בדיקות דפדפן מקצה לקצה (Playwright, python3, ffmpeg)
```

## מבנה
- `js/image.js` זיהוי דף, הומוגרפיה, יישור וניקוי רקע (פונקציות טהורות)
- `js/scan.js` צנרת העיבוד בדפדפן
- `js/camera.js` מצלמה עם זיהוי חי · `js/crop.js` עורך חיתוך · `js/recorder.js` הקלטה
- `js/zip.js` כתיבה וקריאה של ZIP · `js/db.js` אחסון · `js/model.js` חיפוש, קיבוץ, נתיבי גיבוי
- `js/app.js` המסכים
